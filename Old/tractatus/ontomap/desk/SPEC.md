# OntoMap Delivery Spec

`ontomap` should provide the shared semantic edge model for graph relations and support deterministic conversion/projection between ontology formats and practical diagram/query formats.

---

## Real Use Case

We want one canonical ecosystem relation model that can:

- represent graph semantics with the six dimensions
- be projected into Mermaid/PlantUML or query views
- be consumed consistently by graph-facing tools

The first slice should prove one canonical source ontology and one projection path.
