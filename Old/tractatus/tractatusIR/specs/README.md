# Juego de Desambiguación — Spec Wiki

A system for semantic disambiguation using bit-based representations, dimensional context, and logical propositions inspired by Wittgenstein's Tractatus.

## Overview

This spec defines a method to represent concepts as bit vectors within dimensional contexts, enabling:
- Efficient semantic search via hashing-like operations
- Context-sensitive disambiguation
- Logical propositions over concept spaces
- Database storage of facts and relations
