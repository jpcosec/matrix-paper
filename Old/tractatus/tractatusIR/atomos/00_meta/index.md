# Atomos Meta Index

This directory defines the documentary rules for the canonical source.

- `glossary.md`: shared terminology
- `status_model.md`: document lifecycle and authority levels
- `document_rules.md`: atomic writing and transclusion rules
- `migration_status.md`: current migration posture
- `source_atomization_strategy.md`: migrate by decomposing current specs first
- `atomization_status.md`: source coverage status
- `gap_assessment.md`: persistent register of open gaps
- `reviews/`: per-file atomization reviews

`atomos/` is the canonical source.
`docs/` is compiled output.
`specs_raw/` preserves source material during migration.
