## Operation

`insert(concept, context)` inserts a new concept into a local universe through contextual projection.

## Source Algorithm

1. verify minimal membership
2. project to active context
3. encode as signature
4. check for collisions
5. if no collision, insert
6. if collision, add dimension
7. update all indices
8. update horizontal relations

## Canonical Reading

Insertion is not just storage.
It is a local semantic integration process governed by context, encoding, and collision handling.
