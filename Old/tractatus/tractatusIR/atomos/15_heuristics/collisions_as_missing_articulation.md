# Collisions As Missing Articulation

Source anchor:

- `specs/spec_main.md`

## Core Claim

Collisions are not primarily errors.
They signal that the current representation lacks enough structure to distinguish the local candidates.

## Source Rule

If two concepts share the same local signature, add another dimension rather than forcing premature total representation.

This is reflected in the source rules:

1. do not represent everything upfront
2. context activates dimensions
3. collisions signal missing structure
4. add dimensions only when needed
