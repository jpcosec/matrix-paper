# Why Indexing Becomes Representation

Source anchor:

- `specs/spec_main.md`

## Core Claim

In this system, contextual representation is not separate from indexing.
The same projection can serve simultaneously as:

- representation
- contextual hash
- search path
- basis for horizontal relations

## Source Basis

The source spec defines:

- vertical index
- contextual index
- signature index
- horizontal index

and ties them to the same contextual projection pipeline.

Key phrase preserved from the source:

> A concept is a stable node. A context selects a projection. The projection generates a signature. The signature serves as hash, search path, and basis for horizontal relations.

## Immediate Interpretation

Indexing becomes representational when the index keys remain semantically interpretable rather than opaque positions.
