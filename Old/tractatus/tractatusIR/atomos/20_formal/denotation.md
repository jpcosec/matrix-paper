# Denotation

Source anchors:

- `specs/formalization/mathematical_formalization.md`
- `specs/operations/boolean_algebra.md`

## Definition

Denotation maps a well-formed query or signature to a subset of the local universe.

```text
denote(q, K) -> subset of U_K
```

## Canonical Role

Denotation supports the semantic status split:

- meaningful proper subset
- tautological whole universe
- contradictory empty set
