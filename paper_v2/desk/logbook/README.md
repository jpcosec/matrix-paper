# Workflow logbook

This directory stores high-level workflow log entries.

Scope rules:

- only workflow-harness actions and reflections belong here
- do not use this directory for project-domain design or product content
- reference tasks, pills, rituals, specs, commits, and workflow changes explicitly
- record stable workflow knowledge as atoms elsewhere and reference them here

- `models:WorkflowLogEntryDoc`
