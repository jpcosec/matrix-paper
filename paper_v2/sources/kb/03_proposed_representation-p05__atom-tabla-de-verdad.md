## Excerpt

Una tabla de verdad exhibe el valor de una función lógica $f(x_1, \dots, x_n)$ para cada una de las $2^n$ combinaciones posibles de variables booleanas de entrada. Define un mapeo exhaustivo $f: \{0,1\}^n \to \{0,1\}$.
