DESK principle for Matrix: context pills are not just ADRs; they exist to eliminate any possible ambiguity. Pills must be atomized as much as possible and explain what, why, how, and what for. Pills are individually indexed by tasks so that decisions do not drift or disappear across contexts or agents. Tasks should follow the same principle: maximize granularity, keep dependencies explicit, and prefer file-level or function-level actions (e.g. delete files 1,2,3; split file X; move functions A,B,C into new modules) over vague goals like 'clean all legacy'. This is specifically intended to allow phased execution and parallel subagent work with minimal context contamination.
