From repo root `Matrix/`: install editable package with `pip install -e .`; run CLI with `python cli.py examples/vegetales.yaml --status zanahoria hoja.rugosa`; query with `python cli.py examples/vegetales.yaml --query tallo`; inspect tautologies with `python cli.py examples/vegetales.yaml --tautologies`; inspect ambiguity with `python cli.py examples/vegetales.yaml --ambiguous`; run tests with `pytest`; run a specific test file with `pytest tests/test_matrix_engine.py -v` or `pytest tests/test_unified.py -v`.
