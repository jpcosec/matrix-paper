Top-level workspace contains a nested Python package repo in `Matrix/` plus documentation in `TractatusKnowledgeMachine/`. Important code paths inside `Matrix/`: `src/matrix_engine.py` = core dict-based single-context engine; `src/boolean_matrix_engine.py` = more matrix-oriented boolean engine; `src/unified_engine.py` = unified multi-context engine with bridges and subcontexts; `src/context_composition.py` and `src/subcontext_routing.py` = composition/routing variants; `src/nl_parser.py` = natural language parsing/validation; `cli.py` = CLI wrapper; `examples/*.yaml` = sample schemas; `schemas/schema.yaml` = schema definition; `tests/` = pytest coverage for core and unified engines.
