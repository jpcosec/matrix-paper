Project name: Matrix Engine. Purpose: a Python logical/semantic engine that models 'Sense Matrices' to separate truth (M_i) from applicability/sense (S_i) for propositions inside contexts. It supports boolean and multicontext reasoning, contextual applicability checks, ambiguity and tautology detection, context bridges/subcontexts, and a small natural-language parsing layer. Main user entrypoint is the CLI in `Matrix/cli.py`, driven by YAML schemas such as `Matrix/examples/vegetales.yaml` and `Matrix/examples/unified.yaml`. There is also a larger adjacent documentation vault under `TractatusKnowledgeMachine/` with whitepaper/architecture notes in Spanish.
