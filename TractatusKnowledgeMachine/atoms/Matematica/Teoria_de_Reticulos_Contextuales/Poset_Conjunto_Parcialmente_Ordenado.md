# Conjunto Parcialmente Ordenado (Poset)

Estructura $(P, \le)$ donde la relación binaria $\le$ es:
1. Reflexiva: $a \le a$
2. Antisimétrica: $a \le b \land b \le a \implies a = b$
3. Transitiva: $a \le b \land b \le c \implies a \le c$
