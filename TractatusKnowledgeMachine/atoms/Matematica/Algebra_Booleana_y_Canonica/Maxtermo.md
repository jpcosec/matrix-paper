# Maxtermo ($M_k$)

Suma lógica (OR) en la cual todas las variables del sistema aparecen exactamente una vez. Un maxtermo evalúa a $0$ para una única combinación de entradas. Utilizado para representar restricciones o *cortocircuitos* lógicos.
