## Qué es
Es el macro-marco arquitectónico del sistema. Define que un texto se descompone en tres capas: Superficie ($S$, el texto original reversible), Significado ($M$, la matriz/s-expression lógica operable), y Grafo ($G$, el índice de relaciones y dimensiones).

## Por qué es necesario
Resuelve el problema de los LLMs modernos: tienen mucho poder estadístico pero nula garantía lógica. SMG permite tener un sistema donde el LLM propone estructuras (oráculo), pero el motor lógico verifica y ejecuta, sin perder nunca el texto original.

## Cómo funciona
Mediante un proceso ETL: el lenguaje natural se extrae ($S$), se traduce a hechos atómicos y se filtra por sentido ($M$), y luego sus propiedades se indexan para permitir búsquedas y expansiones ($G$).

## Cuándo interviene
Define el flujo completo de vida de un dato desde que entra como lenguaje natural hasta que se procesa como matriz booleana.

## Dónde reside
Es el paradigma que rige toda la arquitectura del Tractatus Knowledge Machine.

## Para qué / Para quién
Para alinear la salida probabilística de las redes neuronales con un entorno completamente verificable y auditable.
